💻 INSTALLATION & LOCAL SETUP

1. Clone the repository:  
   `git clone https://github.com/anunnaki7/Master-Perionica.git`  
2. Navigate to project folder:  
   `cd Master-Perionica`  
3. Install dependencies:  
   `npm install`  
4. Run locally:  
   `npm run dev`  

Open http://localhost:3000 in your browser.
